## 📌 Información del Proyecto

### Nombre del Proyecto
**Voces de Mujeres Unidas - Villa Baviera**

### Descripción General
Sitio web oficial de la Agrupación Voces de Mujeres Unidas, una organización sin fines de lucro dedicada a la reparación histórica y apoyo integral a los sobrevivientes de la ex-Colonia Dignidad (actual Villa Baviera) en Chile.

### Propósito
Transformar la memoria histórica en esperanza, proporcionando apoyo integral a tres generaciones de sobrevivientes mientras se preserva la verdad histórica para evitar la repetición de violaciones a los derechos humanos.

---

## 🏛️ Contexto Histórico

### ¿Qué es Villa Baviera?

Villa Baviera, anteriormente conocida como **Colonia Dignidad**, es un asentamiento ubicado en la comuna de Parral, Región del Maule, Chile. Durante décadas (1961-1997), funcionó como una secta alemana liderada por Paul Schäfer, donde se cometieron sistemáticas violaciones a los derechos humanos, incluyendo:

- **Abuso infantil sistemático**
- **Trabajo forzado sin remuneración**
- **Tortura y desaparición de opositores políticos durante la dictadura**
- **Aislamiento total del mundo exterior**
- **Separación forzada de familias**

### La Transformación

Desde 2005, el territorio ha experimentado un proceso de transformación, y en 2017 nace la **Agrupación Voces de Mujeres Unidas** para:
- Apoyar a los sobrevivientes y sus descendientes
- Preservar la memoria histórica
- Construir un futuro digno para las familias afectadas
- Educar sobre los derechos humanos

- Navegador web moderno

### Pasos de Instalación

1. **Clonar el repositorio**
```bash

```

2. **Abrir en navegador**
```bash

open index.html  # macOS
start index.html # Windows

# Opción 2: Usar servidor local
python -m http.server 8000  # Python 3
# Luego visitar http://localhost:8000
```

3. **Configurar editor**
- Instalar extensiones para HTML/CSS/JS
- Configurar formateo automático
- Habilitar linting
